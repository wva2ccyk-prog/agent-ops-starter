# Handoff Template

Copy this when giving the model a bounded task (especially in a fresh session).
Filled-in handoffs are disposable — save them in an `archive/` folder if worth
keeping, never in `docs/`.

```md
# <Task Title>

This is a bounded execution task. Read this file first, then execute.
Do not stop at analysis or recap.

## Goal

<one exact outcome>

## Read First

1. this file
2. <only the specific files needed — or "nothing else">

## Scope

Do: <what is in scope>
Do not: <what is out of scope — adjacent cleanup, redesign, extra features>

## Success Criteria

Pass only if:
1. <verifiable criterion>
2. <verifiable criterion>

## Stop Conditions

Stop and report instead of improvising if:
1. <condition, e.g. a needed file/tool is missing>
2. anything on the OPERATING_PRINCIPLES escalation list comes up

## Return

Report: pass/fail, result paths, what changed, blocker or first next step.
Then update docs/STATE.md.
```
